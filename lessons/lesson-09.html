Заняття 15-16 Практичне 2 год.

Арифметичний корінь n-го степеня, його властивості

Розділ І. Функції, їхні властивості і графіки

Мета План Теорія Приклади Завдання Домашнє Література

🎯 Мета заняття

Формувати поняття кореня \(n\)-го степеня та арифметичного кореня \(n\)-го степеня. Ознайомити з тотожностями, властивостями та правилами розв'язування рівнянь вигляду \(x^n = a\).

📋 План заняття

  1. Поняття кореня n-го степеня
  2. Арифметичний корінь n-го степеня
  3. Тотожності та область визначення
  4. Розв'язування рівнянь вигляду $x^n = a$

📖 Теоретичний матеріал

1. Поняття кореня n-го степеня

Квадратним коренем із числа \(a\) називають таке число, квадрат якого дорівнює \(a\).

Наприклад,

числа \(4\) і \(-4\) є квадратними коренями із числа \(16\), бо \(4^2 = 16\) і \((-4)^2 = 16\).

Квадратного кореня із числа \(-9\) не існує, бо немає числа, квадрат якого дорівнює \(-9\).

Коренем \(n\)-го степеня із числа \(a\) називають таке число, \(n\)-й степінь якого дорівнює \(a\).

Наприклад:

корінь третього степеня із числа \(64\) дорівнює \(4\), оскільки \(4^3 = 64\).

Числа \(3\) і \(-3\) є коренями четвертого степеня із числа \(81\), бо \(3^4 = 81\) і \((-3)^4 = 81\).

Коренем п'ятого степеня із числа \(-32\) є число \(-2\), оскільки \((-2)^5 = -32\).

2. Арифметичний корінь n-го степеня

Арифметичним квадратним коренем з невід'ємного числа \(a\) називають таке невід'ємне число, квадрат якого дорівнює \(a\). Аналогічно дається означення і для \(n\)-го степеня.

Арифметичним коренем \(n\)-го степеня з невід'ємного числа \(a\) називають невід'ємне число, \(n\)-й степінь якого дорівнює \(a\).

Позначають: \(\sqrt[n]{a}\),
де \(n\) — показник кореня,
\(a\) — підкореневий вираз.
Знак кореня \(\sqrt{\quad}\) називають радикалом.

Якщо \(n=2\), маємо арифметичний квадратний корінь \(\sqrt{a}\) (показник не пишуть). Якщо \(n=3\), маємо арифметичний кубічний корінь \(\sqrt[3]{a}\).

3. Тотожності та область визначення

З означення випливає, що для будь-якого \(a \ge 0\), \(n \in \mathbb{N}\), \(n \ge 2\) маємо тотожність:

\((\sqrt[n]{a})^n = a\)

Наприклад: \((\sqrt[7]{17})^7 = 17\); \((-4\sqrt[4]{8})^4 = (-1)^4 \cdot (\sqrt[4]{8})^4 = 1 \cdot 8 = 8\).

Для коренів непарного степеня з від'ємних чисел використовують тотожність:

\(\sqrt[n]{-a} = -\sqrt[n]{a}\) (для непарних \(n\))

Отже, вираз \(\sqrt[n]{a}\) має зміст:

  • при парному \(n\) — лише для \(a \ge 0\);
  • при непарному \(n\) — для будь-якого значення \(a\).

4. Розв'язування рівнянь вигляду \(x^n = a\)

Розглянемо рівняння \(x^n = a\), де \(a \in \mathbb{R}\), \(n \in \mathbb{N}\), \(n \ge 2\):

  • Якщо \(n\) — парне і \(a > 0\), рівняння має два корені: \(x = \sqrt[n]{a}\) та \(x = -\sqrt[n]{a}\).
  • Якщо \(n\) — парне і \(a = 0\), рівняння має єдиний корінь \(x = 0\).
  • Якщо \(n\) — парне і \(a < 0\), рівняння коренів не має.
  • Якщо \(n\) — непарне, рівняння має єдиний корінь \(x = \sqrt[n]{a}\) (для будь-якого \(a\)).

💡 Приклади

Приклад 1 (Задача 1). Знайти значення виразів:

1) \(\sqrt[3]{27} = 3\), бо \(3 > 0\) і \(3^3 = 27\);

2) \(\sqrt[4]{16} = 2\), бо \(2 > 0\) і \(2^4 = 16\);

3) \(\sqrt[5]{\frac{1}{32}} = \frac{1}{2}\), бо \(\frac{1}{2} > 0\) і \(\left(\frac{1}{2}\right)^5 = \frac{1}{32}\);

4) \(\sqrt[7]{0} = 0\), бо \(0 \ge 0\) і \(0^7 = 0\).

Приклад 2 (Задача 2). Знайти значення виразу: $$(\sqrt[5]{3^4 + 5^2 + 137}).$$

Розв'язання: Спочатку знайдемо значення підкореневого виразу, а потім добудемо корінь 5-го степеня:

\(\sqrt[5]{3^4 + 5^2 + 137} = \sqrt[5]{81 + 25 + 137} = \sqrt[5]{243} = 3\).

Відповідь: 3.



Приклад 3 (Задача 3). При яких значеннях \(x\) має зміст вираз:

1) \(\sqrt[7]{x+2}\);

Розв'язання:

Корінь 7-го (непарного) степеня існує для будь-якого значення підкореневого виразу.

Тому вираз має зміст для будь-якого значення \(x\).

Відповідь: \(x \in \mathbb{R}\).



2) \(\sqrt[4]{2x-10}\)?

Розв'язання:

Корінь 4-го (парного) степеня має зміст лише тоді, коли підкореневий вираз невід'ємний.

Розв'яжемо нерівність:

\(2x - 10 \ge 0\),

звідки \(x \ge 5\).

Відповідь: \(x \ge 5\).



Приклад 4 (Задача 5). Розв'язати рівняння:

1) \(x^4 = 81\);

Розв'язання:

\(x = \pm\sqrt[4]{81} = \pm 3\).



2) \(x^6 = -1\);

Розв'язання:

Оскільки \(n=6\) (парне), а \(a=-1 < 0\), то коренів немає.



3) \(x^5 = 19\);

Розв'язання:

Оскільки \(n=5\) (непарне), то рівняння має єдиний корінь \(x = \sqrt[5]{19}\) (ірраціональне число).



4) \((2x - 1)^8 = 1\).

Розв'язання:

Маємо:

\(2x - 1 = \sqrt[8]{1}\) або \(2x - 1 = -\sqrt[8]{1}\).
\(2x - 1 = 1 \Rightarrow x = 1\);
\(2x - 1 = -1 \Rightarrow x = 0\).
Отже, рівняння має два корені: 0 і 1.
