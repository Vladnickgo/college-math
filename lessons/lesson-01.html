📖 Теоретичний матеріал

1. Означення функції

Числовою функцією називається залежність, при якій кожному числу $x$ з деякої множини $D$ відповідає єдине число $y$ з множини $E$.

Записують: $$y = f(x),$$

де $x$ — незалежна змінна (аргумент),

$y$ — залежна змінна (функція).

Позначення функцій

Функції позначають латинськими (інколи грецькими) літерами: $f$, $g$, $h$, $\varphi$, $\psi$ тощо.

Приклад

Розглянемо функцію $f$, у якої кожному натуральному значенню $x$ від $1$ до $5$ відповідає число $y$, удвічі більше за $x$ (мал. 1.1). Стрілка вказує на число $y$, яке відповідає числу $x$.

Мал. 1.1. Відповідність між $x$ та $y$ для функції $y = 2x$

Число $y$ називають значенням функції $f$ у точці $x$ і позначають через $f(x)$.

На малюнку 1.1, зокрема, $f(3) = 6$.

2. Аргумент і функція

Нагадаємо, що незалежну змінну $x$ ще називають аргументом функції, а про залежну змінну $y$ кажуть, що вона є функцією від цього аргументу.

3. Область визначення і область значень

  • Область визначення $D(f)$ — множина всіх значень аргументу $x$, при яких функція існує.
  • Область значень $E(f)$ — множина всіх значень $y$, які набуває функція.

Приклад 1. Знайти область визначення функції $y = \dfrac{1}{x - 3}$.

Розв'язання:

Знаменник не може дорівнювати нулю:

$x - 3 \neq 0 \Rightarrow x \neq 3$.

Отже, $D(y) = (-\infty; 3) \cup (3; +\infty)$.

4. Способи задання функції

  1. Аналітичний: $y = 2x + 1$
  2. Табличний: таблиця відповідності
  3. Графічний: графік на координатній площині
  4. Словесний: опис словами

💡 Приклади

Приклад 2. Знайти $D(y)$, якщо $y = \sqrt{x - 2}$.

Розв'язання: Підкореневий вираз має бути невід'ємним: $x - 2 \geq 0 \Rightarrow x \geq 2$.

$D(y) = [2; +\infty)$.

Приклад 3. Знайти $D(y)$ для $y = \dfrac{\sqrt{x + 4}}{x - 1}$.

Розв'язання:

1) $x + 4 \geq 0 \Rightarrow x \geq -4$

2) $x - 1 \neq 0 \Rightarrow x \neq 1$

$D(y) = [-4; 1) \cup (1; +\infty)$.

✏️ Завдання для самостійної роботи

  1. Знайдіть область визначення функції: $y = \dfrac{2}{x + 5}$.
  2. Знайдіть $D(y)$ для $y = \sqrt{3 - x}$.
  3. Знайдіть $D(y)$ для $y = \dfrac{1}{\sqrt{x - 1}}$.
  4. Знайдіть $D(y)$ для $y = \dfrac{x + 2}{x^2 - 9}$.
  5. Обчисліть $f(2)$, якщо $f(x) = x^2 - 3x + 1$.
