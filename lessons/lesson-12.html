🎯 Мета заняття

Навчальна

Узагальнити та систематизувати знання про степеневу функцію, її властивості та графіки; відпрацювати навички розв'язування рівнянь вигляду \(x^\alpha = m\) та порівняння степеневих виразів.

Розвивальна

Розвивати логічне мислення, вміння аналізувати, порівнювати та узагальнювати; розвивати графічну культуру та обчислювальні навички.

Виховна

Виховувати самостійність, наполегливість, уважність та інтерес до математики.

📖 Теоретичний матеріал (повторення)

Означення. Функцію вигляду \(y = x^\alpha\), де \(\alpha\) — деяке стале число, називають степеневою.

Властивості степеневої функції \(y = x^\alpha\)

\(\alpha\) Область визначення Парність Монотонність
\(\alpha = 0\) \(x \neq 0\) парна стала \(y = 1\)
\(\alpha > 0\), неціле \([0; +\infty)\) ні парна, ні непарна зростає на \([0; +\infty)\)
\(\alpha < 0\), неціле \((0; +\infty)\) ні парна, ні непарна спадає на \((0; +\infty)\)

Розв'язування рівняння \(x^\alpha = m\)

  • Якщо \(m < 0\), то рівняння коренів не має (степінь з дробовим показником завжди додатний).
  • Якщо \(m = 0\) і \(\alpha > 0\), то рівняння має єдиний розв'язок: \(x = 0\).
  • Якщо \(m = 0\) і \(\alpha < 0\), то рівняння розв'язків не має.
  • Якщо \(m > 0\), то рівняння має єдиний корінь: \(x = m^{\frac{1}{\alpha}}\).

Порівняння степеневих виразів

Для порівняння виразів вигляду \(a^\alpha\) і \(b^\alpha\) використовують властивості степеневої функції:

  • Якщо \(\alpha > 0\), то більшій основі відповідає більше значення степеня (функція зростає).
  • Якщо \(\alpha < 0\), то більшій основі відповідає менше значення степеня (функція спадає).

Формули скороченого множення та заміна змінної

Для рівнянь, що зводяться до квадратних, використовують заміну \(t = x^n\). Наприклад, рівняння \(x^4 - 5x^2 + 4 = 0\) зводиться до квадратного заміною \(t = x^2\).

Мал. 21.1. Графіки функцій \(y = x^{\frac{1}{2}}\) та \(y = x^{-\frac{1}{2}}\)

💡 Розібрані приклади

Приклад 1. Обчислити:

1) \(25^{\frac{1}{2}}\);

2) \(64^{\frac{1}{3}}\);

3) \(36^{1{,}5}\);

4) \(32^{-\frac{4}{5}}\).

Розв'язання:

1) \(25^{\frac{1}{2}} = \sqrt{25} = 5\);

2) \(64^{\frac{1}{3}} = \sqrt[3]{64} = 4\);

3) \(36^{1{,}5} = 36^{\frac{3}{2}} = \sqrt{36^3} = \sqrt{46656} = 216\);

4) \(32^{-\frac{4}{5}} = \sqrt[5]{32^{-4}} = \sqrt[5]{\frac{1}{32^4}} = \frac{1}{\sqrt[5]{1048576}} = \frac{1}{16}\).

Приклад 2. Розв'язати рівняння:

1) \(x^4 = 81\);

2) \(x^6 = -1\);

3) \(x^5 = 19\);

4) \((2x - 1)^8 = 1\).

Розв'язання:

1) \(x^4 = 81\). Оскільки показник степеня парний, то \(x = \pm\sqrt[4]{81} = \pm 3\).

Відповідь: \(3; -3\).

2) \(x^6 = -1\). Оскільки \(x^6 \ge 0\) для будь-якого \(x\), то рівняння коренів не має.

Відповідь: коренів немає.

3) \(x^5 = 19\). Оскільки показник степеня непарний, то рівняння має єдиний корінь \(x = \sqrt[5]{19}\).

Відповідь: \(\sqrt[5]{19}\).

4) \((2x - 1)^8 = 1\). Маємо: \(2x - 1 = \sqrt[8]{1}\) або \(2x - 1 = -\sqrt[8]{1}\); \(2x - 1 = 1\) або \(2x - 1 = -1\); \(x = 1\) або \(x = 0\).

Відповідь: \(0; 1\).

Приклад 3. Порівняти числа:

1) \(7^{1{,}2}\) і \(7{,}2^{1{,}2}\);

2) \(1{,}8^{-0{,}4}\) і \(2^{-0{,}4}\).

Розв'язання:

1) Розглянемо степеневу функцію \(y = x^{1{,}2}\). Оскільки показник \(1{,}2 > 0\), то функція зростає на \((0; +\infty)\). Оскільки \(7 < 7{,}2\), то \(7^{1{,}2} < 7{,}2^{1{,}2}\).

2) Розглянемо функцію \(y = x^{-0{,}4}\). Оскільки показник \(-0{,}4 < 0\), то функція спадає на \((0; +\infty)\). Оскільки \(1{,}8 < 2\), то \(1{,}8^{-0{,}4}> 2^{-0{,}4}\).

Приклад 4. Розв'язати рівняння:

1) \((x - 3)^2 = 5\);

2) \((x + 1)^{0{,}5} = 0\);

3) \((x - 2)^{-\frac{1}{3}} = 0\);

4) \((x^2 - 2)^{0{,}5} = \sqrt{7}\).

Розв'язання:

1) \((x - 3)^2 = 5\). Оскільки показник парний, то \(x - 3 = \sqrt{5}\) або \(x - 3 = -\sqrt{5}\). Звідси \(x = 3 + \sqrt{5}\) або \(x = 3 - \sqrt{5}\).

Відповідь: \(3 \pm \sqrt{5}\).

2) \((x + 1)^{0{,}5} = 0\). Маємо \(x + 1 = 0\), звідси \(x = -1\).

Відповідь: \(-1\).

3) \((x - 2)^{-\frac{1}{3}} = 0\). Оскільки \(m = 0\) і \(\alpha = -\frac{1}{3} < 0\), то рівняння розв'язків не має.

Відповідь: \(\varnothing\).

4) \((x^2 - 2)^{0{,}5} = \sqrt{7}\). Маємо \(x^2 - 2 = 7\), звідси \(x^2 = 9\), \(x = \pm 3\).

Відповідь: \(3; -3\).

Приклад 5. Розв'язати рівняння \(x^4 - 5x^2 + 4 = 0\).

Розв'язання:

Зробимо заміну \(t = x^2\), \(t \ge 0\). Тоді рівняння набуває вигляду \(t^2 - 5t + 4 = 0\). За теоремою Вієта \(t_1 = 1\), \(t_2 = 4\).

Повертаємося до заміни:

1) \(x^2 = 1\), звідси \(x = \pm 1\);

2) \(x^2 = 4\), звідси \(x = \pm 2\).

Відповідь: \(1; -1; 2; -2\).
