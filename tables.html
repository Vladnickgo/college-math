1.2. Основні тригонометричні тотожності

Основна тотожність
$$\sin^2 \alpha + \cos^2 \alpha = 1$$
Тангенс і котангенс
$$\text{tg}\, \alpha = \dfrac{\sin \alpha}{\cos \alpha}$$
Котангенс
$$\text{ctg}\, \alpha = \dfrac{\cos \alpha}{\sin \alpha}$$
Зв'язок tg і ctg
$$\text{tg}\, \alpha \cdot \text{ctg}\, \alpha = 1$$
Через косинус
$$1 + \text{tg}^2\, \alpha = \dfrac{1}{\cos^2 \alpha}$$
Через синус
$$1 + \text{ctg}^2\, \alpha = \dfrac{1}{\sin^2 \alpha}$$

1.3. Формули додавання

$$\sin(\alpha \pm \beta) = \sin\alpha \cos\beta \pm \cos\alpha \sin\beta$$
$$\cos(\alpha \pm \beta) = \cos\alpha \cos\beta \mp \sin\alpha \sin\beta$$
$$\text{tg}(\alpha \pm \beta) = \dfrac{\text{tg}\,\alpha \pm \text{tg}\,\beta}{1 \mp \text{tg}\,\alpha \cdot \text{tg}\,\beta}$$

1.4. Формули подвійного кута

$$\sin 2\alpha = 2\sin\alpha \cos\alpha$$
$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha$$
$$\cos 2\alpha = 1 - 2\sin^2\alpha = 2\cos^2\alpha - 1$$
$$\text{tg}\,2\alpha = \dfrac{2\,\text{tg}\,\alpha}{1 - \text{tg}^2\,\alpha}$$

🔢 Степені та корені

2.1. Властивості степенів

$$a^m \cdot a^n = a^{m+n}$$
$$\dfrac{a^m}{a^n} = a^{m-n}$$
$$(a^m)^n = a^{mn}$$
$$(ab)^n = a^n b^n$$
$$\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$$
$$a^0 = 1, \quad a \neq 0$$
$$a^{-n} = \dfrac{1}{a^n}$$
$$a^{\frac{m}{n}} = \sqrt[n]{a^m}$$

2.2. Властивості коренів

$$\sqrt[n]{a \cdot b} = \sqrt[n]{a} \cdot \sqrt[n]{b}$$
$$\sqrt[n]{\dfrac{a}{b}} = \dfrac{\sqrt[n]{a}}{\sqrt[n]{b}}$$
$$\sqrt[n]{a^m} = a^{\frac{m}{n}}$$
$$\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}$$
$$(\sqrt[n]{a})^n = a$$
$$\sqrt[n]{a^n} = |a| \text{ (n — парне)}$$

📐 Логарифми

3.1. Означення та основна тотожність

$\log_a b = c \iff a^c = b$, де $a > 0$, $a \neq 1$, $b > 0$.

Основна логарифмічна тотожність: $a^{\log_a b} = b$.

3.2. Властивості логарифмів

Добуток
$$\log_a (bc) = \log_a b + \log_a c$$
Частка
$$\log_a \dfrac{b}{c} = \log_a b - \log_a c$$
Степінь
$$\log_a b^n = n \log_a b$$
Корінь
$$\log_a \sqrt[n]{b} = \dfrac{1}{n} \log_a b$$
Перехід до нової основи
$$\log_a b = \dfrac{\log_c b}{\log_c a}$$
Обернений логарифм
$$\log_a b = \dfrac{1}{\log_b a}$$
$$\log_a a = 1, \quad \log_a 1 = 0$$
$$a^{\log_a b} = b, \quad \log_{a^n} b^m = \dfrac{m}{n}\log_a b$$
