Програмне забезпечення, браузер і твій перший HTML

Крок за кроком розберемось, як комп'ютер «розуміє» веб-сторінки, які файли відкриває браузер, і створимо власну сторінку з нуля — прямо на занятті.

Що таке програмне забезпечення?

Програмне забезпечення (ПЗ) — це всі програми, які «оживляють» комп'ютер. Без них залізо — просто набір мікросхем. Усе ПЗ поділяють на три великі родини.

Системне ПЗ

«Фундамент» комп'ютера: операційна система, драйвери, службові утиліти. Керує залізом і запускає інші програми.

Windows · Linux · macOS

Прикладне ПЗ

Програми «для людей»: браузери, текстові редактори, ігри, плеєри, месенджери. Саме з ними ми працюємо щодня.

Chrome · Word · Zoom

Інструментальне ПЗ

Середовища, у яких програмісти створюють інші програми: редактори коду, компілятори, відлагоджувачі.

VS Code · DevTools

Браузер — це прикладне ПЗ, яке перетворює «сирий» код на красиву сторінку. Він — наше вікно в інтернет і головний робочий інструмент сучасного вчителя.

Навіщо потрібен браузер?

Браузер — це «перекладач» між людиною та веб-сервером. Ви вводите адресу — браузер надсилає запит, отримує код сторінки, читає його та малює на екрані те, що ви бачите.

Які файли вміє відкривати браузер?

Сучасний браузер — це універсальна «читалка» форматів. Він розуміє не лише сайти, а й багато локальних файлів.

HTML .html / .htm
CSS .css
JS .js
PDF .pdf
IMG .png / .jpg / .svg
JSON .json

Цікаво: браузер не «малює» HTML сам по собі — він будує дерево елементів (DOM) і за стилями CSS вирішує, як кожен блок виглядатиме. Саме тому одна й та ж сторінка може виглядати по-різному в різних браузерах.

Практика: створюємо перший HTML

Створимо файл index.html і подивимось, як браузер його читає. Праворуч — живе прев'ю, яке оновлюється автоматично.

index.html — код
index.html 
<!-- Мій перший HTML-документ -->
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Моя сторінка</title>
</head>
<body>
  <h1 style="color:#2563eb;">Привіт, гурток!</h1>
  <p>Це мій перший абзац на HTML.</p>
  <img src="" alt="Кошеня">
</body>
</html>
Живий результат

Як це влаштовано?

Теги

<h1>, <p>, <img> — «команди» для браузера. Вони кажуть, що це за елемент: заголовок, абзац, зображення.

Атрибути

src — шлях до файлу, alt — текстова альтернатива, style — «швидкі» стилі прямо в тезі.

Структура

<head> — «мозок» сторінки (заголовок вкладки, кодування), <body> — усе, що бачить користувач.

Спробуйте змінити властивості: у коді праворуч додайте до <h1> атрибут style="color:#e11d48; text-align:center;" — заголовок стане рожевим і по центру. Прев'ю оновиться автоматично.

Меню розробника (DevTools)

Це «рентген» для будь-якої веб-сторінки. Відкрити можна клавішею F12 або Ctrl+Shift+I (Mac: ⌘+Option+I), або правим кліком → «Переглянути код».

1
Elements

HTML-структура у вигляді дерева. Можна змінювати текст, атрибути й стилі прямо в браузері.

2
Console

Повідомлення, помилки JavaScript, результати виконання команд.

3
Network

Список усіх файлів і запитів, які завантажує сторінка. Звідси видно, чи все «доїхало».

4
Sources / Styles

Підключені CSS та JS-файли. Тут можна ставити точки зупинки й аналізувати код.

На що звертати увагу: червоні рядки в Console — помилки; жовті трикутники — попередження; статус 404 у Network означає, що файл не знайдено; 500 — проблема на сервері.
